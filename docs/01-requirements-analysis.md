# 需求分析

## 原始需求

用户希望开发一款 Windows 桌面软件，用于将 CS:GO / CS2 的 config 文件从一个 Steam 账号快速迁移到另一个 Steam 账号。

### 功能需求

1. **自动扫描 CS:GO 安装路径**
   - 自动检测 Steam 安装目录。
   - 支持手动设置/修正路径。
2. **自动列出 config 文件夹及对应 SteamID**
   - 扫描 `userdata/<SteamID3>/730/local/cfg/`。
   - 展示每个账号的配置状态（是否存在、文件列表、最后修改时间）。
3. **基准 config 管理**
   - 允许用户指定一个账号的 config 作为“基准配置”。
   - 支持将基准配置一键应用到其他 Steam 账号。
   - 目标账号可能从未运行过 CS:GO/CS2，即目录结构可能不存在，需要自动创建。
4. **安全性**
   - 应用前自动备份目标账号原有配置。
   - 操作日志可追溯。

### 非功能需求

- 运行在 Windows 10/11。
- 界面简洁，操作步骤少。
- 无需安装依赖或依赖尽量精简。
- 对游戏文件只做读取和受控写入，不修改游戏本体。

### 边界与约束

- 只处理本地 Steam 安装和本地 `userdata`。
- 不处理 Steam 云同步冲突（由 Steam 客户端自行处理）。
- 不解析或转换 CS:GO 与 CS2 之间的配置指令差异，只做文件级复制。
- SteamID 展示以 SteamID3 为主，昵称为可选增强项。
